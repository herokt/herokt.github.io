# herokt.github.io
Herokt Developer Page

앱마다 폴더 하나에 공개 페이지(소개·개인정보 처리방침·약관·계정 삭제·지원)를 둔다. 앱 저장소에는 사본을 두지 않는다.
`app-ads.txt` 는 루트 하나로 모든 앱을 덮는다.

| 폴더 | 앱 | 원본 |
|---|---|---|
| `bladecrawl/` | 칼의 던전 | 이 저장소 |
| `butim/` | 붙임 | 이 저장소 |
| `calendar/` | 한줄 캘린더 | 이 저장소 (2026-11-26 hanjul-calendar-site 저장소에서 옮김) |
| `footballcrew/` | Football Crew | 이 저장소 (2026-11-26 Firebase Hosting 에서 옮김) |
| `harugrim/` | 하루그림 | 이 저장소 (2026-11-26 Firebase Hosting 에서 옮김) |
| `slidemates/` | 다같이 미끄럼 | 이 저장소 |
| `zonber/` | ZONBER | 지원 페이지 = zonber 저장소 `node scripts/make_support_page.mjs` 가 만든다 |

딥 링크(`/join`, `/match`, `/get`), 앱 내려받기 페이지(`/app`), 관리자 페이지(`/secret_admin`)는 각 앱의 Firebase Hosting 에 남아 있다.
